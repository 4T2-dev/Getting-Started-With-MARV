=======================================
MARV Platform Directive Cheat Sheet
=======================================

This cheat sheet provides a quick reference for configuring and utilizing MARV platform directives.

Directive Summary Table
-----------------------

.. list-table:: MARV Platform Features
   :widths: 25 45 30
   :header-rows: 1

   * - Feature / Component
     - Purpose
     - Configuration Method
   * - API Endpoint
     - Connects extension to MARV tutorial server.
     - https://marv.computing.edgehill.ac.uk
   * - Student ID
     - Identifies student for course progress tracking.
     - User icon in header -> Input prompt
   * - Cloud Modules (☁️)
     - Openly available learning modules.
     - Direct click to expand
   * - Lock Modules (🔒)
     - Passcode-protected learning modules.
     - Click lock icon -> Enter passcode
   * - Workspace Folder
     - Target working directory for exercises.
     - Click 'No folder open' prompt or Explorer
